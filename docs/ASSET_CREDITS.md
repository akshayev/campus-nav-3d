# Asset Credits

Third-party assets used in this project, with source and licence. Add a row whenever a new outside asset goes in.

## Characters (avatars)

| What | Author | Source | Licence |
|---|---|---|---|
| Male and female base characters (`Character_Male.fbx`, `Character_Female.fbx`), hairstyles `Hair_Male.fbx` (SimpleParted) and `Hair_Female.fbx` (Long), and colour textures (`Male_Body`, `Male_Hair`, `Female_Body`, `Female_Hair`, `Eyes`) | Quaternius (@Quaternius) | Universal Base Characters (Standard, free version): https://quaternius.itch.io/universal-base-characters | CC0 1.0 Universal (public domain), https://creativecommons.org/publicdomain/zero/1.0/ (text quoted from `License_Standard.txt` in the download) |

Notes:
- Only the `Unity` FBX files and the colour (BaseColor) textures were used. Normal and roughness maps were left out to keep the WebGL build small.
- Textures are capped at 1024 px in Unity's import settings.
- CC0 does not require credit, but we credit the author anyway.

The `.wav` files in `Assets/Audio` are placeholder sounds generated by a small Python script (`docs/PHASE_LOG.md`, Phase 13), so there is no third-party licence. `door_open.wav` is not mentioned in that Phase 13 entry, so its origin is **not recorded**.
