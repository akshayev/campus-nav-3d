# /reference

Reference material for the exterior and interior modeling work — not Unity assets, not Blender sources.

Holds:
- Reference photos of the actual main B.Tech building and MCA block (facade, atrium, roofline, etc.)
- Hand-sketched floor plans and measurements from team walkthroughs (per `docs/PROJECT_KNOWLEDGE_BASE.md` Section 3 — no official campus map or floor plans exist)

This is source material teams consult before/while modeling in Blender. The actual Blender working files live in `/Blender`; the actual Unity project lives in `/UnityProject`.

## building_exterior/
Four photos of the main building's outside (taken by the team, 2026-10-11): `building_front.jpeg` (entrance side, pink facade with blue glass stairwell, red tile roofs), `building_back.jpeg`, `building_front_left.jpeg` (glass tower + porch), `building_right.jpeg` (side wall with mural). For the Blender modellers: use them for the footprint, roofline, window rhythm and colours, and later as facade texture references. `building_front.jpeg` is also copied into the Unity project as the Main Building popup photo.
